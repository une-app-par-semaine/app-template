# Politique de sécurité

## Signaler une faille

Merci de **ne pas ouvrir d'issue publique**.

Utilisez l'onglet **Security** de ce dépôt, puis **Report a vulnerability**. Votre signalement reste privé jusqu'à sa correction.

Indiquez si possible : la version concernée, les étapes pour reproduire, l'impact estimé.

## Ce qui se passe ensuite

- Accusé de réception sous 7 jours.
- Si la faille est confirmée : correctif, nouvelle version et mention dans `AUDIT.md`. Vous êtes remercié dans les notes de version si vous le souhaitez.

## Versions suivies

Seule la dernière version publiée reçoit des correctifs de sécurité.

## Périmètre

Cette application est 100 % locale : elle ne contacte aucun serveur. Tout comportement réseau inattendu est en soi un problème de sécurité à signaler.
